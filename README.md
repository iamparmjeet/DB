# DB

Runnable database learning labs. Each numbered directory is a technology track; each module groups a concept rather than mirroring a single video.

## Tracks

- [`02-Postgres`](./02-Postgres/README.md) — PostgreSQL from fundamentals through query planning and performance.

## Conventions

- Keep executable SQL, setup files, and observed benchmark output with the lab that produced them.
- Use `README.md` in a module to record its source playlist/video, goal, commands, observations, and next experiment.
- Do not commit credentials, database dumps, or machine-specific Docker volumes.

`01-Mongoose` remains in the archived [BackendDB](https://github.com/iamparmjeet/BackendDB) repository. It can be rebuilt here later only if it becomes an active learning track.
